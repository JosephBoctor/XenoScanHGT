# XenoScan1

XenoScan1 is a machine-learning framework for alignment-free detection of horizontal gene transfer (HGT) through host-relative genomic discordance.

## Download

The standalone Windows package is available under **Assets** in the [XenoScan1 v1.0.0 release](https://github.com/JosephBoctor/XenoScanHGT/releases/tag/v1.0.0).

Download the ZIP, extract it, and follow the included instructions.
