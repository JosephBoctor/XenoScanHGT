# Security Policy

## Supported versions

Security reports are currently accepted for the latest published release, XenoScan1 v1.0.0.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Contact Joseph Boctor at joseph.tanyous@gmail.com with the subject line "XenoScan1 security report". Include the affected version, operating system, steps to reproduce and potential impact. Do not include real credentials, private data or sensitive sequence data.

You will receive an acknowledgement as soon as reasonably possible. Please allow time for assessment and remediation before public disclosure.

## Scope

Reports concerning unsafe file handling, dependency vulnerabilities, unintended network exposure, insecure execution or disclosure of local data are relevant. The local browser interface is intended to bind to 127.0.0.1; reports of unintended exposure beyond the local machine are especially important.
